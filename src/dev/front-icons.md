Catálogos de iconos, SVGs y avatares para no reinventar los assets visuales en cada proyecto.

## Iconos

| Recurso                | Enlace                                   | Qué ofrece            |
| ------------------------ | ------------------------------------------- | ------------------------ |
| **Icônes**                | https://icones.js.org                      | Buscador de packs de iconos, copia/paste listo para usar |
| **Iconify**               | https://icon-sets.iconify.design/          | Sets de iconos unificados, un solo componente para todos |
| **Feather Icons**         | https://feathericons.com/                  | Iconos simples y minimalistas               |
| **SVGRepo**               | https://www.svgrepo.com/                   | Repositorio de iconos en SVG                  |
| **HolaSVG**               | https://icons.holasvg.com/                 | Iconos minimalistas                           |
| **Flaticon**              | https://www.flaticon.es/                   | Iconos estilo sticker                         |
| **Tabler Icons**          | https://tabler-icons.io                    | Iconos SVG, set grande y consistente          |
| **Skill Icons**           | https://skillicons.dev/                    | Iconos de tecnologías/stacks para READMEs     |
| **SVGL**                  | https://svgl.app/                          | Logos en SVG                                   |
| **Dashboard Icons**       | https://dashboardicons.com/icons/          | Iconos para dashboards y self-hosted apps     |
| **Pixel Icon Library**    | pixeliconlibrary                            | Iconos estilo pixel art                       |

## Avatares

| Recurso        | Qué ofrece                     |
| ---------------- | ---------------------------------- |
| **Avvvatars**     | Generador de avatares                |
| **unavatar**       | Avatares a partir de un identificador (usuario, email, etc.) |
